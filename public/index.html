About

I build small, sharp tools and run them on hardware I control. Each app on this board is something I use — for family, for the homelab, for staying in shape — not a demo. The board itself is one of them: a custom Node HTTP server with no framework and no runtime dependencies, polling the rest of the fleet every 30 seconds.

The philosophy is minimal upkeep and honest signal. Adding a project here is a one-line edit; the status takes care of itself.
